# taiyo8911.github.io

Taiyoの個人サイト（ハブ）と、アプリの公式ページです。

- 公開URL：https://taiyo8911.github.io
- 独自ドメイン：https://sol-se.com（Cloudflareへの移管後に切り替え予定）

## 構成

| パス | 内容 |
|---|---|
| `index.html` | ハブ（自己紹介・各種リンク） |
| `style.css` | サイト全体の共通デザイン |
| `404.html` | 存在しないURLを開いたときのページ |
| `apps/アプリ名/` | アプリの公式ページ（紹介・FAQ・問い合わせ・プライバシーポリシー） |
| `apps/_template/` | 新しいアプリ用のひな形（`_` で始まるため公開されない） |

Webアプリ本体は、それぞれのリポジトリのGitHub Pagesで公開しています。
独自ドメインに切り替えると、`sol-se.com/リポジトリ名/` で公開されます。

## アプリを追加するとき

1. `apps/_template/` をコピーして `apps/アプリ名/` にする
2. `index.html` のアプリ名・説明・リンクなどを書き換え、`icon.png` を置く
3. ハブ（`index.html`）にリンクを追加する
4. push する（1〜2分で反映）

## App Store Connect に登録するURL（sol-se.com 切り替え後）

| 項目 | URL |
|---|---|
| サポートURL | `https://sol-se.com/apps/アプリ名/` |
| プライバシーポリシーURL | `https://sol-se.com/apps/アプリ名/#privacy` |
| マーケティングURL | 空欄 |
| 利用規約 | Apple標準EULAを使用 |

## 問い合わせ

全アプリ共通のGoogleフォームを1つ使い、フォーム内でアプリを選んでもらう。

## ルール

- アプリのフォルダ名は英小文字とハイフンのみ。一度決めたら変えない
- Webアプリのフォルダ名は、本体のリポジトリ名とそろえる
- `apps` という名前のリポジトリを作らない（URLが衝突するため）
- このリポジトリの直下に、ほかのリポジトリと同じ名前のフォルダを作らない
- GitHubのユーザー名は変えない（URLが変わるため）
- このリポジトリはPublic。サイトのファイル以外（メモ・パスワード等）は置かない
